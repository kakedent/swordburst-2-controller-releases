# Swordburst 2 Controller
By kakeden.

A small Windows tool for managing Swordburst 2 windows, with configurable healing, blocking, skills, and optional Discord controls.

## Download
Get the Windows x64 ZIP from the [latest release](https://github.com/kakedent/swordburst-2-controller-releases/releases/latest), extract it, and run **Swordburst2Controller.exe**.

Open Roblox, click **Scan / Arrange**, choose your settings, then **Start automation**. Default shortcuts: **F6** pause, **F7** exit, **F12** show/hide.

See [release notes](https://github.com/kakedent/swordburst-2-controller-releases/releases) for changes.
